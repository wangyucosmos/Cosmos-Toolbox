# Cosmos OS Roadmap

**版本：v0.1**  
**日期：2026-08-17**

---

## 总原则

Roadmap 只作为方向，不用日期绑架开发。

每个阶段必须达到：

> 可运行 → 可使用 → 可稳定 → 再扩展
