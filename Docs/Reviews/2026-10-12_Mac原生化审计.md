## 0. 结论先行

1. Mac 版**并不是没用玻璃**：全仓已有约 60 处 `.buttonStyle(.glass/.glassProminent)`、5 处 `glassEffect`、1 个 `GlassEffectContainer`。问题是**用法不对、层级混乱**，所以看起来「不原生」：
   - 玻璃按钮被放进**内容区**，并用 `colorScheme == .dark ? .white : .black` 手动改字色（7 个文件、11 处）——这是在对抗系统材质；
   - 玻璃被放进**工具栏里的 `ToolbarItem`**，再套一层自绘 `CosmosGlassToolbarGroup`（`glassEffect` + 圆角矩形）—— macOS 26 的 toolbar 本来就自带玻璃分组，这里是「玻璃叠玻璃」（10 个页面）；
   - 分段控件自绘（`CosmosSegmentedControl`、`CampaignUISegmentedTabs`、知识库分段、搜索来源胶囊、卓望分类标签共 5 套），用 `matchedGeometryEffect` 画强调色滑块，外面再套 `glassEffect`，等于**自己仿造一个系统 Picker**；
   - 内容层是「自绘卡片」：`controlBackgroundColor` + 1px 描边 + 阴影 + 悬停放大/上浮（`CosmosCardStyle`、`CosmosInteractiveCardStyle`、`campaignUICardSurface`、`CosmosContentPanel`），与系统 Form / List / GroupBox 的观感不同；
   - **所有独立窗口（活动详情、产物审阅/比较、笔记/提示词/项目/学习编辑、资产详情，共 10 处 `NSHostingController`）都没有窗口工具栏**：标题、操作按钮、分段标签都画在内容区顶部，背景用 `.bar`。系统工具栏（含玻璃分组、滚动边缘效果）完全没有用上。
2. 手机伴侣应用好看的几个关键，**有一部分在 macOS 上做不到**，不要照抄：`navigationTransition(.zoom)` 在 macOS **不可用**（SDK 标注 `@available(macOS, unavailable)`）；`tabViewBottomAccessory`、`searchToolbarBehavior(.minimize)` 也是 macOS 不可用。macOS 的原生做法是：**侧栏 + 工具栏玻璃 + 滚动边缘效果 + 系统控件**，切页不做 push 动画。
3. 现有的「外壳单层淡入、保留卓望实例」是**正确的 macOS 习惯**，不建议换成任何 `navigationTransition`。原生化应集中在「控件与窗口外观」，不碰切页机制。

## 3. 逐页审计

> 约定：工作量 小 = 单文件、<1 小时级改动；中 = 多文件或需新增测试夹具；大 = 改动窗口/导航结构，需要实机验收。风险列里的「四项」指：①页面切换不闪动 ②卓望保留实例 ③提示词库 Store 身份 ④统一检索聚焦 + 侧栏原生选中。

### 3.1 外壳与侧栏 — `DashboardView.swift`
**现状**：已是原生 `NavigationSplitView` + `List(selection:)` 的 sidebar，选中状态原生（对）。非原生之处：
- L179–184：底部「设置」是 `Divider + Button(.plain)` 自绘行，位置/点击反馈与系统侧栏不一致。
- L446：`.symbolEffect(.bounce, value: pulse)` 每次切换图标弹跳——**装饰性动效**，非 macOS 习惯。
- L255–306：内容切换 = `.transition(.identity)` + 手写 `pageOpacity` 0.65→1 淡入；这是刻意设计（解决过闪动），**保持**。
- 侧栏行用 `VStack(中文+英文)` 且 `frame(minHeight: 30)`，与系统行高不同。
**建议**：
- 设置入口：删除自绘按钮，改用 App 菜单 `Settings` 场景（已有 `Settings {}` scene）+ ⌘, 为主入口；侧栏底部若仍想保留，用 `.safeAreaInset(edge: .bottom)` 放一个 `Label` 行，但不再自画 Divider。（`safeAreaInset` 老 API；也可用 `safeAreaBar`，26.0）
- 删 `symbolEffect(.bounce)`；侧栏图标交给系统。
- 侧栏背景交给系统（不要再叠色）。
**改善**：侧栏更像 Finder / 备忘录；少一块「自画」感。
**风险**：低。设置入口改动要保留 `navigator.settingsRequest` 的 `openSettings()`。不碰 `selection`/`pageOpacity`，不影响四项。
**工作量**：小。

### 3.2 工具栏（全局）
**现状**：各页 `.toolbar { ToolbarItem(placement: .primaryAction) { CosmosGlassToolbarGroup { … }.labelStyle(.iconOnly) } }`（AIWorkspaceView:55、CosmosSettingsView 备份行、DashboardHomeView:127 单按钮 + `.buttonStyle(.glass)`、LearningCenterView:36、MacEnvironmentView:45、ProjectsView:49、PersonalNotesView:~92、PromptVaultView:~66、UnifiedSearchView:108–109 两个按钮各自 `.buttonStyle(.glass)`、KnowledgeSourceViews 底部 toast 的 `glassEffect`）。
**问题**：玻璃叠玻璃；一个 `ToolbarItem` 里塞整组，系统无法按项分组 / 折叠溢出 / 在窄窗自动收进「»」菜单；`.glass` 样式在工具栏里属多余。
**建议**：
- 每个动作一个 `ToolbarItem`，相关的包在 `ToolbarItemGroup`；组间用 `ToolbarSpacer(.fixed)`/`.flexible`；**去掉所有工具栏内的 `.buttonStyle(.glass)`**，让系统决定外观。
- 需要突出的主操作（新建）可单独一项并 `.buttonStyle(.borderedProminent)` / 系统 prominent 工具栏样式——先实机看效果再定，不要预设。
- 需要把某项从共享玻璃背景中拆出：`ToolbarContent.sharedBackgroundVisibility(.hidden)`（26.0）。
**改善**：最大单项视觉改善；工具栏立刻有 macOS 26 的玻璃分组与溢出行为。
**风险**：低到中。工具栏项的 `accessibilityIdentifier`（如 `dashboard-refresh`、`prompt-new`、`notes-new`、`ai-workspace-detect`）要保留，否则 UI 测试/夹具会失效。
**工作量**：中（10 个文件，机械，但要逐页看实机）。

### 3.3 仪表盘 — `DashboardHomeView.swift`
**自绘/非原生**：
- 页头问候 + info 按钮在内容区（L~40）。
- `quickActions`（L~137）：内容区里一整块 `CosmosGlassToolbarGroup`（玻璃放内容层），按钮字色硬编码黑/白（4 处）。
- 指标瓷砖 `CosmosMetricTile` ×7 与图表卡 `CosmosChartCard` ×3：自绘卡片 + 悬停缩放/阴影；`CosmosMetricTile` 里 `contentTransition(.numericText())` 是系统 API，**正确，保留**。
- 「最近更新」列表是 `VStack + Button(CosmosInteractiveCardStyle)`，不是 `List`。
- 状态卡 `CosmosCard`（Mac 环境 / AI 工具）。
- 图表：`Charts`（系统）— 保留。
**建议**：
- `quickActions` 改为普通 `Button`（`.bordered` / `.borderless`）排成一行，或挪进工具栏作为「新建」菜单（`Menu` + `ControlGroup`）；去掉黑白字色硬编码。**这是玻璃使用边界的第一个整改点**。
- 指标瓷砖保留，样式换系统填充（`.background.secondary` + `ConcentricRectangle`/统一圆角），删悬停缩放/阴影。
- 最近更新改 `List(.inset)` 或 `Table`；保持 `navigator.navigate(.record)` 行为。
**风险**：低；`DashboardHomeViewModel` / 缓存不动。注意仪表盘筛选优先逻辑（`pendingWorkbenchMetric`）在 `navigator`，不受影响。
**工作量**：中。

### 3.4 统一检索 — `UnifiedSearchView.swift`
**自绘/非原生**：
- L~42–47：自绘大搜索框（`TextField(.plain)` + `controlBackgroundColor` + 圆角 + 聚焦时画 accent 描边），聚焦逻辑为自维护 `@FocusState` + `navigator.searchFocusRequest*`。
- 来源胶囊 `sourceButton`（`matchedGeometryEffect` + 渐隐 mask）、两个复选框、`DisclosureGroup("来源状态")`。
- 结果行 `Button(.plain)` 套在 `List(.inset)` 里自带 chevron；工具栏两个 `.glass` 按钮。
**建议（两个方案）**：
- 保守（推荐本轮）：保留自绘搜索框与现有聚焦机制，只处理：去掉工具栏 `.glass`；来源胶囊换 `Picker(.segmented)` 或 `Picker(.menu)`；结果行去 chevron，改 `List` 原生选择 + `.onTapGesture`/`Button` 保持点击打开。

**风险**：保守方案低；激进方案**直接碰「统一检索聚焦」**。
**工作量**：保守 小；激进 大。

## 4. 全局建议

### 4.1 保留 / 删除 / 薄包装
**保留（系统没有）**：`CampaignUITimeline`、`CampaignUIProgressRing`（或换 `Gauge`）、`CosmosLoadingSkeleton`、状态胶囊/版本徽标/Chip（合并为一个组件）、`CosmosMetricTile`（指标卡）、`CosmosInfoButton`（popover 属系统）、产物卡片网格、`CosmosWorkflowMiniProgress`、`CosmosNativeSplitWidth`（仅方案 A 需要）。
**删除**：`CosmosGlassToolbarGroup`、`CosmosSegmentedControl`、`CampaignUISegmentedTabs`、`CosmosKnowledgeDestinationView` 中的自绘分段与 `sourceButton`、`categoryNavigation` 自绘分段、`CosmosEntrance`/`campaignUIEntrance`、`cosmosRowFeedback`、`CosmosCardStyle` 的悬停缩放/阴影、侧栏 `symbolEffect(.bounce)`、`KnowledgeHubView`（死代码）、`CosmosMainWindowPolicy`（需确认）、全部 `colorScheme == .dark ? .white : .black` 字色硬编码。
**改成薄包装**：`CosmosEmptyState` → `ContentUnavailableView`；`CosmosContentPanel` / `campaignUICard*` / `CosmosCardStyle` → 同一个「系统填充面板」修饰器；`CosmosPageHeader` → `navigationTitle/Subtitle` + 可选说明行；`CosmosCard` → 系统填充面板 + 标题行。

### 4.2 玻璃使用边界（依据 HIG 原则 + SDK 事实，落地前请对照 HIG 原文）
- **只给导航/控件层**：工具栏（系统自动）、侧栏（系统自动）、sheet/popover/菜单（系统自动）、窗口内**浮层**（toast、悬浮操作条、`safeAreaBar` 底部操作栏）。
- **内容层一律系统填充**：卡片、面板、列表行、表格、编辑区使用 `.background`/`.fill` 系列与 `ConcentricRectangle`，不用 `glassEffect`。
- **不叠加**：工具栏内不再加 `.glass`/`glassEffect`；玻璃内不再放玻璃；同一视图里多个邻近玻璃元素必须放进一个 `GlassEffectContainer`（`glassEffectID`/`Union` 只用于确有形变需求的浮层）。
- **按钮**：内容区用 `.bordered` / `.borderedProminent`；`.glass/.glassProminent` 只用于**悬浮在内容之上**的按钮（例如图片/预览上的操作）。
- **不手动改玻璃上的字色**。需要强调用 `.tint`/`Glass.tint`，不要靠强制黑白。
- 当前违规点清单（便于逐项消除）：DashboardHomeView 4、CosmosDesignComponents 1、KnowledgeSourceViews 2、ZhuowangAssetCenterView 1、ZhuowangCampaignView 1、ZhuowangProvinceManagementView 1、ZhuowangWorkspaceView 1 处强制字色；10 页 `CosmosGlassToolbarGroup`；约 60 处内容区 `.glass` 按钮。

### 4.3 转场与滚动规范
- **切页**：保持「外壳单层淡入 + 内容 identity 替换，不做插入/移除动画」（DashboardView L255–306）。macOS 没有 push 转场语义，`navigationTransition(.zoom)` 不可用；**不要引入**。
- **页内状态切换**（空/加载/结果、标签内容）：默认**不做动画**或仅 `.opacity`；删除 `offset(y: 8)` 一类自制位移。
- **数值/图标变化**：只用 `contentTransition(.numericText())`、`contentTransition(.symbolEffect(.replace))`（均 macOS ≥13/14 可用）。删除装饰性 `symbolEffect(.bounce)`、入场错峰。
- **滑块类选中动画**：用系统 `Picker(.segmented)` 自带，不再自画 `matchedGeometryEffect`。
- **滚动**：内容在工具栏/安全区下滚动时，依赖系统默认滚动边缘效果；仅在需要时用 `scrollEdgeEffectStyle(.soft/.hard, for:)`、`scrollEdgeEffectHidden`（26.0）。有顶部自绘条的页面（`.bar` 背景）改为不再需要。`backgroundExtensionEffect()` 只用于大图/封面类内容，Cosmos 暂无此类页，可不用。`scrollTransition` 不建议（桌面信息密度页面不需要）。
- **减少动效**：保持现有 `CosmosMotionPolicy`（系统 `accessibilityReduceMotion` OR 用户偏好 → `transaction.disablesAnimations`）。删除大量自定义动画之后，它的维护成本会下降；仍须保留，因为系统控件的动画也经它降级。

### 4.4 统一做法清单
1. 主窗口各页：`navigationTitle` + `navigationSubtitle` + `.toolbar`；内容区不再写页面大标题。
2. 独立窗口：统一工厂创建，`window.title/subtitle` + `sceneBridgingOptions=[.toolbars]` + `.toolbar`。
3. Sheet：`NavigationStack` + toolbar 的 cancellation/confirmation 项。
4. 表单类页面：`Form(.grouped)`；列表类：`List`/`Table`；空/错误态：`ContentUnavailableView`。
5. 自绘只留「系统没有」的那一小撮（见 4.1）。

## 7. 明确不建议改动的部分及理由
1. **切页机制**（`DashboardView` 的 `pageOpacity` 单层淡入、`.transition(.identity)`、`didVisitWorkspace` 保留卓望实例）：上一轮用 72 对切换矩阵验证过；macOS 没有 push 转场，换成 `navigationTransition` 既不可用也会重新引入闪动。
2. **卓望保留实例的 `ZStack`**：Store 身份、二级选择记忆都依赖它。原生化时只**适配**它（工具栏显隐绑定），不重写它。
3. **提示词库的 `CosmosPromptSession` / `@StateObject` 来源与 `init`**：只改外观修饰。
4. **统一检索的聚焦机制**（`searchFocusRequest*`、侧栏点击清除请求、⌘F）：文档里仍有一个未闭环的断言，不要在此基础上叠加 `.searchable` 改造；等 Codex 闭环后再评估 3.4。
5. **侧栏 `List(selection:)` 的原生选中**：已正确，不要再包任何自绘选中。
6. **预览渲染器**（`ArtifactHTMLRenderer`/`ArtifactPDFRenderer`/`ArtifactImageRenderer` 与其安全策略）、**Markdown 渲染器**（`KnowledgeSourceMarkdownRenderer`）：这是内容绘制与安全边界，与系统控件无关。
7. **图表**（`Charts`）、`Gauge`：已是系统控件。
8. **时间线、进度环、产物卡片网格、状态徽标**：系统无对应控件，保留并统一即可。
9. **设置窗口的 `Settings` scene + `TabView` + `Form(.grouped)`**：已原生，仅清理备份页即可。
10. **减少动效策略**（`CosmosMotionPolicy` + 用户偏好）：保留；它与系统 Reduce Motion 的叠加规则是已验收行为。
11. **各 Store / 数据格式 / 窗口管理器的窗口复用语义**（`ZhuowangCampaignWindowManager` 按 campaign.id 复用窗口等）：窗口外观可改，生命周期与 identifier 不改。
12. **`.glassEffect` 用于浮层（如知识库 toast）**：符合玻璃用法，保留。
